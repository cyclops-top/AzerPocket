# AzerPocket

A personal World of Warcraft addon manager for macOS — **early development**.

## Project scope

AzerPocket is planned to help a small group of 2–4 users download, install, update, and back up WoW addons. It is a non-commercial personal project with no fees, advertising, subscriptions, or donations.

This repository currently contains the project overview and website. The desktop application is not available yet.

## Planned features

- Addon downloads and installation for the selected WoW client version.
- Version checks and updates.
- Local addon backups and restoration.
- Author credits and links to original project and support pages where available.

## CurseForge integration

API access has not yet been approved. Planned integration will retrieve addon metadata, check versions, and download files permitted for third-party distribution, subject to approval and applicable terms. AzerPocket will respect authors’ distribution settings and will not operate a public addon mirror. Local backups are for users’ installed addons.

AzerPocket is an independent project, not affiliated with or endorsed by Blizzard Entertainment, Overwolf, or CurseForge. Third-party addons retain their respective licenses.
